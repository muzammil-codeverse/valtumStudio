# V1 scope

V1 is planned as a premium marketing and lead-generation system with structured content,
secure administration, lightweight lead workflow, SEO, observability, and purpose-built
desktop and mobile public compositions. Phase 2 implements only the PostgreSQL data
foundation for structured content and leads; the user-facing capabilities remain to be
implemented.

The architecture keeps one application, backend, content source, database, URL system,
and SEO model so later desktop and mobile presentations share business logic rather than
duplicate it.
