# Phase 1 scope

Phase 1 delivers the repository and Next.js foundation: pinned runtime and pnpm, strict
TypeScript, environment validation, a minimal public route and health endpoint, errors
and logging primitives, quality tools, tests, Docker, CI, Dependabot, security baseline,
and engineering documentation.

It explicitly excludes database access, Prisma, authentication, administration, CMS,
leads, email, analytics, Sentry, final pages, final visual system, mobile navigation,
payments, AI integrations, and external CRM integrations.
