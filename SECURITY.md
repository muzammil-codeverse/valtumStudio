# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities publicly before the project owner has had a
reasonable opportunity to investigate and remediate them. The project owner must add an
approved private reporting contact before production launch. Until then, report through
the private project-owner channel already agreed by the participating team; do not
include credentials or exploit details in public issues.

## Supported versions

The current V1 development branch is supported while it is actively maintained. No
released production version exists during Phase 1.

## Response expectations

Reports will be acknowledged and assessed as capacity permits. This project does not
make a fixed remediation-time guarantee. Confirmed issues will be handled according to
impact, exploitability, and available mitigation.
